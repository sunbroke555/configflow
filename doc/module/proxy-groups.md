# 策略组

策略组是一组可供选择的出口。入口为 **当前配置 → 策略组**。每个配置空间分别保存自己的组，节点来源可直接选择共享订阅、节点和聚合。

## 创建一个能用的组

1. 确认订阅已经更新，或节点库里已有可用节点。
2. 点击「添加策略组」，名称填「代理选择」。
3. 类型先选「手动选择」。
4. 在节点来源中勾选「订阅」，然后选择订阅；使用手动节点时勾选「节点」，在「包含节点」中选择它们。
5. 筛选条件可以先留空，保存。
6. 到「策略规则」把需要代理的规则指向这个组，再生成配置并更新客户端或发布 Agent。

## 选哪种类型

| 类型 | 作用 | 适合场景 |
| --- | --- | --- |
| 手动选择 `select` | 在目标客户端或 Mihomo 面板手动切换 | 自己决定使用哪个出口 |
| 自动测速 `url-test` | 由目标核心根据探测结果和容差选路 | 希望自动选择延迟较低的节点 |
| 故障转移 `fallback` | 按顺序优先使用可用候选 | 主线路不可用时使用备用线路 |
| 负载均衡 `load-balance` | 按所选算法分配不同连接 | 多个可用节点分担连接 |
| 代理链 `chain` | 先经过前置出口，再经落地出口访问目标 | 仅用于 Mihomo 的多跳连接 |

负载均衡提供 `consistent-hashing`、`round-robin` 和 `sticky-sessions`；它不会把一个连接的带宽叠加成多个节点带宽。

## 自动组的检查参数

以下是**新建**自动测速、故障转移和负载均衡组的默认值。已有组保留原设置，不会因打开页面自动替换。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 测试 URL | `https://www.gstatic.com/generate_204` | 检查节点访问这个地址的结果 |
| 间隔 | `60` 秒 | 目标核心检查间隔 |
| 超时 | `5000` 毫秒 | 单次检查允许等待的时间 |
| 预期状态码 | `204` | 判断成功所需的 HTTP 状态码 |
| 懒检查 `lazy` | 关闭 | 由目标核心按该设置决定空闲时是否检查 |
| 容差 | `50` 毫秒 | 仅自动测速组使用，避免小幅差异导致频繁切换 |

Provider 的健康检查有独立默认值，不能用上表代替，见 [订阅来源](subscription.md#三种间隔各管什么)。

页面的「批量测速地址」可以为当前配置的自动组统一修改 URL，保留各组其他参数。保存后仍需更新客户端配置或发布 Agent。

## 选择节点来源

| 来源 | 怎么用 |
| --- | --- |
| 订阅 | 选择一个或多个已添加的订阅 |
| 节点 | 从共享节点库选择手动节点，也可加入内置直连、拒绝候选 |
| 聚合 | 选择已建立的订阅聚合 |
| 策略 | 引用其他已存在的策略组或命名链，形成多层选择 |
| 跟随 | 复制另一个普通策略组的类型、来源、筛选和检查参数，只保留自己的名称 |

**跟随不是只复制节点列表。** 如果需要使用相同订阅、但采用不同策略类型，请分别创建组并选择同一订阅。跟随来源与其他来源互斥，不能跟随代理链。

## 按名称筛选

订阅和聚合可以分别设置「保留正则」和「排除正则」。可以把它们理解为节点名称的筛选条件：先保留匹配项，再排除不需要的项。

| 想要的结果 | 保留正则 | 排除正则 |
| --- | --- | --- |
| 所有节点 | 留空 | 留空 |
| 香港或日本 | `香港\|日本` | 留空 |
| 排除说明和到期节点 | 留空 | `广告\|剩余流量\|到期` |
| 精确排除两个名称 | 留空 | `^(香港 01\|日本 02)$` |

表格里的 `\|` 用于显示正则中的竖线，填写时使用普通 `|`。可点击「预览」查看最终候选。后端统一校验表达式，支持 `(?i)` 忽略大小写；表达式错误时会说明原因，并保留上次预览。

这些条件不筛选手动勾选的节点或引用的策略组。筛选后没有可用候选时，应先修正来源或条件再生成。

## 代理链，仅 Mihomo

在添加策略组时选择代理链，填写名称、前置引用和落地引用。两端可以使用手动节点、普通组或已有链；订阅与聚合通过组引用，不能循环依赖。

- 前置组沿用原组当前的选择。
- 落地组生成链专用副本，在链内独立选择或测速。
- 原始节点和组仍可单独使用。
- 落地不能包含无法施加前置拨号的 `DIRECT` / `REJECT` 候选。
- Surge 不能导出启用的代理链；MosDNS / OxiDNS 不会因此获得多跳代理功能。

完整结构和限制见 [Mihomo 代理链](nodes.md#mihomo-代理链)。

## 修改、排序和删除

修改组后重新生成并更新客户端，或发布到绑定该配置的 Agent。调整顺序后需要保存；只在面板中排序不会立即改变设备。

仍被规则、其他组或代理链使用的组不能直接删除；先解除引用。节点库测速从面板所在机器发起，不能用它推断目标设备自动组当前选中了哪个节点，实际选择以目标设备的面板为准。
