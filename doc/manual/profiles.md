# 配置空间

[文档首页](../README.md)

入口：**系统 → 配置空间**。可以把它理解为“家庭”“办公室”各一份方案：规则和软件设置分开保存，订阅、节点、聚合和规则库仍共用。

本页目录：[新建与切换](#新建与切换) · [卡片上的操作](#卡片上的操作) · [导入已有配置](#导入已有配置) · [调整设备归属](#调整设备归属) · [删除前检查](#删除前检查)

## 新建与切换

1. 点 **新建配置空间**。
2. 标识 ID 用简短英文或数字，例如 `home`。允许字母、数字、下划线、短横线，须以字母或数字开头，最长 64 个字符；创建后不能修改。
3. 名称填自己看得懂的中文，例如“家里使用”。说明可以留空，也可写“客厅电视和家用电脑”。
4. 点 **保存**，再从卡片或页面顶部切换到这个空间，确认顶部显示的名字正确。

切换空间只是改变你正在编辑哪份方案，不会让已经绑定其他空间的设备自动改用新方案。

## 卡片上的操作

| 按钮 | 做什么 | 使用建议与结果 |
| --- | --- | --- |
| 使用 | 把当前编辑对象换成该空间 | 修改规则前先确认顶部名称；不会自动发布 |
| 编辑 | 改名称和说明 | 标识 ID 不可改；保存后更新显示名称 |
| 设为默认 | 改变未指定空间的配置链接、新登记 Agent、MCP 及尚未选择空间的浏览器标签页采用的默认方案 | 会先询问；已经绑定的 Agent 保持原归属，当前标签页已选择的空间也不会自动切换 |
| 创建副本 | 复制策略、规则和模板等方案内容 | 推荐用于尝试新方案；共用资源不复制一遍，路由器接入信息和自动同步设置不复制 |
| 导出 | 下载该空间自己的配置 JSON | 适合保存单份方案；不包含所有共享资源，完整迁移用系统设置的导出全部数据 |
| Agent 绑定 / 已绑定设备 | 查看使用此空间的设备，或批量改绑 | 改绑规则见下文，不能理解成“复制原空间的设置到另一空间” |
| 删除 | 删除该空间的设置、缓存和生成文件 | 该空间的配置链接会失效，共享资源保留；先处理绑定设备 |

## 导入已有配置

### 导入 ConfigFlow 配置空间

顶部 **导入备份到当前**（手机在“导入”菜单里）会把选中的 ConfigFlow 空间文件导入**当前空间**。选择文件后就会开始导入，没有额外的覆盖确认，也不会自动新建一个空间。推荐先新建空白空间并切换过去，再导入；覆盖已有方案前先导出。

### 导入其他客户端的配置

**导入客户端配置**会建立一个新的配置空间，支持 Mihomo / Clash Meta、Surge、Loon、Shadowrocket。

| 选项 / 按钮 | 怎么用 | 结果 |
| --- | --- | --- |
| 配置类型 | 选原文件实际所属的软件 | 解析规则按这个软件处理，不是随便选一个输出目标 |
| 配置名称 | 给新方案起名字 | 导入后在空间列表显示 |
| 标识 ID（可选） | 不熟悉时留空 | 自动生成可用 ID；手填仍遵守新建规则 |
| 配置内容 / 选择文件 | 粘贴完整配置，或选本地文件 | 选择文件只是读取文字，尚未导入 |
| 展开编辑 / 收起编辑 | 放大或恢复编辑区域 | 不改变内容，也不保存 |
| 为筛选型策略组关联订阅 | 原配置按名称筛选全部节点、且希望它继续使用现有订阅时勾选 | 勾选的订阅加入相应筛选组；不勾选就不额外关联这些现有订阅 |
| 解析预览 | 推荐先点 | 查看会新增、复用哪些内容及不能转换的警告，不写入配置 |
| 导入 | 确认预览后点击 | 新建空间；节点、订阅、规则集加入共享资源，相同定义的资源会复用 |

出现不支持某些内容的警告时，逐条核对。成功导入不保证每种软件的所有高级能力都能转换，也不会自动把配置发到设备。

## 调整设备归属

点卡片上的 **Agent 绑定**，选择“改绑到”的目标空间，再点 **解除绑定并改绑**。

这个对话框会把列表中的**全部 Agent 一起改绑**，没有逐台勾选；只想调整一台时，到 Agent 页修改该设备的配置空间。

改绑保留接入信息、已部署文件和发布记录；原空间的规则、DNS 设置不会复制过去。本次不推送配置、不重启服务，但**后续拉取或发布会使用目标空间**。先在目标空间准备好配置，再改绑。

## 删除前检查

- 还有 Agent 绑定时，先改绑到其他空间；无法确认绑定情况时先刷新，不要重复提交。
- 删除默认空间时，需要选一个接任的默认空间；最后一个空间不能这样直接删空。
- 删除空间不会清空共享订阅和节点，也不会代替远程设备的停止、卸载或网络回退操作。
